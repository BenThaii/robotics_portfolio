The stack

Three steps, no controller between them and the robot.

1 · RETARGET

BVH → G1, two pipelines

CMU Graphics Lab clips retargeted onto the G1 by per-frame bounded differential IK (Pinocchio) and by GMR (Araújo et al., ICRA 2026 — external open-source work).

2 · TRACK

Torque PD in MuJoCo

tau = kp·(q★−q) + kd·(q̇★−q̇) + gravcomp with kp=300, kd=8, on all 29 joints. Pure joint torques — nothing else drives a joint.

3 · HONEST BASE

The pelvis is unactuated

A soft workspace PD stands in for a balance controller. With the base fully free, the same joint PD tracks at 0.045 rad and still topples in 0.43 s.

Honest scope — what this is NOT

Simulation only. The pelvis loop is a stand-in for a real balance/locomotion controller — with the base fully free the robot topples in 0.43 s (reported as a result, not hidden). Mesh self-collision is off. GMR is external open-source work (Araújo et al., Stanford, ICRA 2026, MIT licence) — not a group algorithm.
